📊 FLSM vs VLSM Comparison

📐 FLSM (Fixed Length Subnet Mask)

  • ✅ All subnets have the same size
  • ✅ Easier to manage and configure
  • ✅ Simpler routing tables
  • ❌ Can waste IP addresses
  • ❌ Not efficient for varying host needs

Best for: Networks with similar-sized departments

📊 VLSM (Variable Length Subnet Mask)

  • ✅ Subnets have different sizes
  • ✅ Efficient IP address utilization
  • ✅ Allocates based on actual needs
  • ❌ More complex to manage
  • ❌ Requires careful planning

Best for: Networks with varying host requirements

📖 Subnetting Concepts & Formulas

🔢 Number of Subnets

2n

Where n = number of bits borrowed from host portion

🖥️ Number of Hosts per Subnet

2h - 2

Where h = number of host bits remaining. Subtract 2 for network & broadcast addresses

📊 Block Size / Increment

256 - Subnet Mask Octet Value

Determines the increment between subnet network addresses

🎭 Wildcard Mask

255.255.255.255 - Subnet Mask

Used in access control lists (ACLs) and OSPF configurations
